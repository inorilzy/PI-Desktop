一句话回顾

  • 现状已核实：pi.requestTurnAbort() 已实现（runtime.turn.abort，high）——refusal 返回 false 并记诊断，不静默。
  • 无载荷、返回布尔：有轮在跑就请求中止；插件自己的长任务同时收到取消信号（同一个决定的两半）。
  • 滥用面：插件可以随意杀掉用户在跑的轮——对策是装时确认 + 审计；无速率限制（只影响用户自己的轮）。
  • 不管：别的会话、伪造结束原因、事后抵赖。

还没定的事

中止在界面上的呈现（是否标注「由插件中止」）——见 requirements.html 的「本轮拍板（待定）」。
