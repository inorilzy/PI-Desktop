turn-continue · 数据流

一条消息从插件到宿主队列、再变成一轮署名续跑的路径。六节固定：接口约定 / 数据怎么走 / 出错怎么办 / 不提供什么 / 相关条目 / 还没定的事。

status: draft · issue #561 · 字段名是建议值

1接口约定 建议

headless API，runtime.turn.continue。入队即返回，不等工作跑完。

// 插件 headless（建议形态）
const { queuedTurnId } = await pi.continueTurn({
  message: "开始 B 步骤：把结果写入报告",
})
// 对话里出现插件署名的排队行；轮按队列顺序跑

语义表

方面内容
输入{ message }——要续跑的指令文本
返回{ queuedTurnId }
署名宿主补 { pluginId, pluginLabel } 落库——行以插件名义可见
配额现状无上限（ADR 0295 规则 9）
权限runtime.turn.continue，装时确认

3出错怎么办 已核实

情况结果靠什么保证
队列入满 / 会话在跑按队列语义排队或拒绝（现值：入队）宿主队列语义
message 为空拒绝 + 诊断入参校验
无权限permission_denied槽权限门控
用户中止队列照常可清，轮立即停中止键语义

4不提供什么 已核实

不给为什么
无署名续跑可见性是前提，不存在隐藏通道
用户身份冒充署名由宿主补，插件伪造不了
跨会话续跑只推自己所在会话
后台静默运行轮在用户会话里，受中止键管
