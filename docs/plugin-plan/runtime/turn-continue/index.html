turn-continue · 宿主续跑

插件往队列里推一条消息让宿主接着跑一轮：pi.continueTurn()。消息以插件署名出现在对话里——这是它区别于「无声注入」的立身之本。总表「内部用了」只说对一半：插件面 API 已实现且有 e2e。

一句话回顾

  • 现状已核实：pi.continueTurn({ message }) 经宿主队列 session.queuePush 入列，带插件署名（runtime.ts:2794-2804）；返回 { queuedTurnId }。
  • 署名是底线：续跑永远是插件署名的可见行（ADR 0293，schema v22）——不允许无署名、不允许隐藏。
  • 无配额：现状没有任何上限（ADR 0295 规则 9 有意如此），闸门是「用户看得见、随时能停」；要不要加可选上限待拍板。
  • 与 closing 分工：closing 是轮末的被动询问（有预算）；continue 是主动 API（无预算）。

还没定的事

署名的展示形态、要不要可选上限——见 requirements.html 的「本轮拍板（待定）」。
