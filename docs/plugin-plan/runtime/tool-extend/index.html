tool-extend · 工具结果的增强能力

插件自己的工具在结果里可以多做三件事：往循环里引入新工具、上报花费、请求整轮终止。宿主在两侧门控这组字段。总表「工具执行期间」的标签有误导——它不是执行中途的钩子。

一句话回顾

  • 现状已核实：内核字段 addedToolNames / usage / terminate（AgentToolResult）存在；运行时与 Electron 主进程两侧门控——没授权就剥离字段并审计 PERMISSION_DENIED。
  • 归属明确：只作用于插件自己的工具的结果，管不了别家工具，也管不了宿主工具。
  • 不是中途钩子：长任务进度是工具自己的 onUpdate（走 watch 事件）；往循环里追消息是 closing / continue 的事。
  • 三件事：引入工具（界面上署名插件）、报告花费、请求批量终止。

还没定的事

usage 上报的展示位、terminate 与 abort 的关系——见 requirements.html 的「本轮拍板（待定）」。
