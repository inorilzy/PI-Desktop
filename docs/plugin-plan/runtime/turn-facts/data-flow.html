1接口约定 建议

headless API，runtime.turn.facts（低风险）。拉取式，显式调用。

// 不传 turnId = 查当前轮（建议形态）
const facts = await pi.turnFacts()
// → { status, tokens, provider, model, toolCallCounts, touchedFiles, … }
// 没有任何提示之前：undefined
// 查无此轮：报错，不返回零值

4不提供什么 已核实

不给为什么
对话文本定位是数字与清单；文本归 recap（且单轮正文同缺）
跨会话只查本会话的轮
写路径纯读
零值误导查无此轮报错，不给全零对象
