一句话回顾

  • 现状已核实：runtime.session.lifecycle 已注册（trusted-extensions.ts:190-198, 546）；create / delete 由桌面 emit（session-ipc.ts:261, 453）、switch / fork 由桌面转发（202-217, 317-324）、compact 由 sidecar 自发（runtime.ts:6393-6405）。
  • 五种时刻：created / deleted / switch（before_switch）/ fork（before_fork）/ compact（before_compact · compact · compact_failed）。
  • 唯一否决权：before_compact 可返回 { cancel: true }——其余全是 fire-and-forget，不等待、不可拦（ADR 0295 规则 11）。
  • 不管：否决切换 / fork / 删除、原生 Pi 会话（桌面不经手的事件它听不到）。
