一句话回顾

  • 现状已核实：11 个内核事件映射到 runtime.turn.watch，对普通插件开放（风险 medium）；ADR 0295 明确否决了「只给高信任」的说法。
  • 纯观察：fire-and-forget，返回值没人看，改不了轮、拦不了工具、不保证送达（无超时、无回执、无重投）。
  • 事件族：agent_start / agent_end / turn_start / turn_end / message_start·update·end / tool_execution_start·update·end / after_provider_response。
  • 不管：任何写路径——要拦工具走 tool-gate，要续跑走 turn-closing / turn-continue。
