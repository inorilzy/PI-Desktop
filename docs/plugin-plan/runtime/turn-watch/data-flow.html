一条单行道：内核事件镜像给插件，插件什么都不回。六节固定：接口约定 / 数据怎么走 / 出错怎么办 / 不提供什么 / 相关条目 / 还没定的事。

status: draft · issue #561 · 字段名是建议值

1接口约定 建议

headless 事件监听，runtime.turn.watch（medium）。fire-and-forget：没有超时、没有回执、没有重投。

// 插件 headless 入口（建议形态）
pi.on("turn_start",   ({ turnIndex }) => myMeter.begin(turnIndex))
pi.on("tool_execution_start", ({ toolName }) => myMeter.tick(toolName))
pi.on("turn_end",     ({ message }) => myMeter.finish(message))
// 返回值被丢弃；慢了也不影响运行

2数据怎么走 已核实

host 运行时 slot 钩子边界 plugin 插件 headless
宿主（运行时）
钩子边界
插件 headless
  • 内核事件发生agent / turn / message / tool
  • 逐事件镜像runtime.ts:2372-2404
  • fire-and-forget emit不等插件、不看返回
  • 运行照常推进观察者慢/挂都不阻塞
  • 按槽权限过滤没授权的插件收不到
  • 尽力而为无回执无重投无顺序承诺
  • 背压待拍板高频 update 是否节流
  • broker 缺口沙箱插件未接（ADR 0292）
  • 只读消费统计 / 进度 / 审计
  • 自己扛丢事件不得当可靠日志用
  • 要参与走别处gate / closing / continue

3出错怎么办 已核实

情况结果靠什么保证
插件处理慢 / 抛错运行完全不受影响；诊断记录fire-and-forget + 非结果性
插件漏收事件无补救——语义上允许尽力而为的交付语义
插件狂刷日志拖慢自己拖的是插件自己观察者隔离
无权限permission_denied，收不到事件槽权限门控

4不提供什么 已核实

不给为什么
任何写路径返回值被丢弃——观察者无表决权
可靠交付无回执无重投；要可靠读历史走 recap / facts API
跨会话数据事件只属于当前运行
决策参与拦截 / 续跑 / 改结果各归各的钩子
