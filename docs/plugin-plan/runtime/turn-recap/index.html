一句话回顾

  • 现状已核实：pi.recap() 已实现（runtime.ts:2780-2786），槽 runtime.turn.recap；「禁了」不成立。
  • 两种范围：scope:"turn" → 只有事实，正文返回 messages: null（no-host-turn-read）；scope:"session" → 最近消息行（默认 200，封顶 500）+ 截断标记，另需 runtime.session.read。
  • 拉取式：插件自己调，不占发送路径延迟；只读，永不推。
  • 不管：写任何东西、无上限拉取、单轮正文（那是新宿主读取，不是解锁）。

还没定的事

单轮正文要不要补宿主读取——见 requirements.html 的「本轮拍板（待定）」。
