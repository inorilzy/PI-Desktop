1接口约定 建议

headless API，runtime.turn.recap（high）。拉取式：插件调、宿主答、无推送。

// 轮范围：只有事实，没有正文（现状）
const turn = await pi.recap({ scope: "turn", turnId })
// → 事实 + { messages: null, messagesUnavailable: "no-host-turn-read" }

// 会话范围：最近消息行（需另授 runtime.session.read）
const session = await pi.recap({ scope: "session", limit: 200 })
// → { messages: [...], truncated }

两种范围

范围拿到权限
turn该轮事实：状态、token、provider/model、工具计数、动过的文件；正文 = nullruntime.turn.recap
session最近消息行（默认 200，封顶 500）+ truncated+ runtime.session.read
