一句话回顾

  • 撤回是硬的：6 个事件（before_agent_start / context / before_provider_request / before_provider_headers / model_select / thinking_level_select）进了 WITHDRAWN_RUNTIME_EVENTS，runner 拒绝注册并报 rejected_registration。
  • 为什么撤：静默改写整份外发消息 = 无声的提示注入与历史删除，对话里不留痕；风险与收益不成比例。
  • 重开的三个前置：diff 级审计接收 message_list / request_payload、远小于 30 秒的请求级预算、ADR 0295 分期步骤 3 的产品决定。
  • 内核挂点保留：transformContext 等仍按透传接好——重开时是接线问题，不是结构问题。

还没定的事

是否、何时重开——产品决定，见 requirements.html 的「还没定的事」。
