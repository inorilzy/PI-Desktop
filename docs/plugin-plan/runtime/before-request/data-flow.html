当前状态：已撤回，数据不通。本页是假如重开时的设计稿——挂点、载荷与审计长什么样。六节固定。

status: draft · issue #561 · 本页内容全部为建议，未被批准

1接口约定 设计稿

headless 结果性事件，槽 runtime.request.before。以下形状来自撤回前的设计（TrustedExtensionRequestRewriteRecord），仅作重开讨论的底稿。

// 设计稿：非现状
pi.on("before_provider_request", ({ sessionId, turnId, messages, model, thinkingLevel }) => {
  // messages = 整份外发消息列表
  return { messages: rewrite(messages) }   // 或 { cancel: true, reason }
})

设计稿要点

方面内容
输入消息列表 + 模型 id + 思考量 + system prompt + 会话 / 轮次 id
输出改写后的消息列表，或两段式取消
审计（前置）每次改写 diff 级记入 plugin_rewrites——需新增 message_list / request_payload 接收端
预算（前置）请求级同步预算（远小于 30 秒），超时 = 无意见
