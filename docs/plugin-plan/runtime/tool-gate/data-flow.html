tool-gate · 数据流

内核工具循环上的两个挂点：执行前的裁决、执行后的字段级覆盖。六节固定：接口约定 / 数据怎么走 / 出错怎么办 / 不提供什么 / 相关条目 / 还没定的事。

status: draft · issue #561 · 字段名是建议值，以内核类型为准

1接口约定 建议

headless 结果性事件：tool_call / tool_result → runtime.tool.gate。30 秒预算，超时 = 无意见。

// 执行前（建议形态）
pi.on("tool_call", async ({ toolName, toolCallId, input }) => {
  if (await isDangerous(toolName, input))
    return { block: true, reason: "命中危险命令清单，已拦截" }
  // 放行：什么都不返回。没有 args 字段——参数改不了
})

// 执行后
pi.on("tool_result", async ({ toolName, content, isError }) => {
  if (isError)
    return { content: maskSecrets(content), details: "已脱敏" }
  // 字段级覆盖：给哪个字段覆盖哪个，其余原样
})

两个挂点

挂点拿到可返回
tool_call（前）{ toolName, toolCallId, input }{ block, reason, terminate? }；不返回 = 放行
tool_result（后）{ toolName, toolCallId, input, content, details, usage, isError, … }字段级覆盖 { content?, details?, isError?, usage?, terminate? }
权限runtime.tool.gate；refusal 可见

3出错怎么办 已核实

情况结果靠什么保证
插件超时无意见，工具照常执行 / 结果原样30s 预算
插件抛错该次无意见 + 诊断runner 诊断面
两家都要 block第一个（注册序）赢先拦赢折叠
两家都覆盖同一字段按注册顺序，后者覆盖前者字段级合并
block 的 reason 缺失拒绝无效或以默认文案处理（待拍板）入参校验

4不提供什么 已核实

不给为什么
参数改写永久排除——内核类型无 args 字段，包装绕路也被 ADR 0295 规则 4 排除
无限等待30 秒封顶；慢确认走两段式
静默拦截block 必须带 reason；决定可诊断
别家工具的增强权tool-extend 只属于工具的作者插件
