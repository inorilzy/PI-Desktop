一句话回顾

  • 确认卡是固定格式：输入框上方同宽（窄 5px）紧贴的横栏，左内容右按钮；卡壳、位置、按钮样式是宿主的；内容与按钮都走参数（固定字段文案 + ≤3 个按钮，支持下拉形态），点击后 Promise 回调；不接受内容组件、不让自绘。
  • 三种卡型：确认（2 钮 → "ok" | "cancel"）、选择（下拉 → 按下的 actionId）、知会（1 钮 → "ok"）。
  • 排队：权限请求永远第一优先；插件确认卡 FIFO，一次只显示一张，其余折叠成条；不响应 Esc；不设超时；插件卸载时 await 收到 cancel + 原因码。
  • 现状的注册制 modal 槽、overlay 槽、inlineConfirm 接管槽与 ui.openModal 等四个动作在重设计中移除；弹窗 / 悬浮层自理另立文件夹 ui/self-dialog/。
