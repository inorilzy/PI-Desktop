一句话回顾

  • 工具很多、形状各异，所以插件拿到的不是某个工具的原始返回，而是宿主归一后的一份固定数据格式；原始返回块原样附在 result.content 里，不丢信息。
  • 槽只有一个，挂在默认卡的位置上；插件按工具全名认领（不做通配），两个插件认领同一个名字在安装时提示冲突；没认领的工具保持宿主默认卡。
  • 认领的卡拿到：这份固定数据 + 宿主默认卡组件。可以整块换掉，也可以原样复用再包一层。
  • 本期只做展示：凡是带等待性质的——下一步、审批、确认、重试再跑——都不做。
  • Write / Edit 旁的改动审阅卡移到输入框上方固定显示，不再跟着工具卡走。
  • 数据全量给，不截断；显示什么、怎么省是插件自己的事。卡的折叠展开状态也插件管。
  • 运行中的卡也在槽里：流式输出按节拍把新数据递给插件重画。
