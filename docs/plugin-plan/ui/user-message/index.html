一句话回顾

  • 用户发出去的只有附件 + 文字；对象卡不是主故事。
  • entry 换成消息气泡整体；entry.actions 加自己的按钮、去掉宿主的复制 / 编辑 / 删除。
  • entryExtra 已从用户气泡拿掉。
  • 插件至少要有：现成组件、这条消息的完整数据、能调用的操作。
  • 任何插件都能渲染这两个槽，对所有用户消息生效；插件能增删的只有操作栏。
  • 复制给的是存着的内容。
