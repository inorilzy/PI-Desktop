一句话回顾

  • 固定件不许动：左边是附件、模式切换、权限切换；模型选择和发送永远在最右。
  • 中槽里宿主的东西只有上下文用量——现成组件 ContextUsage，默认装在槽里，整项交给插件处置：可隐藏、可替换、可重排（排序声明见数据流页）。插件之间仍按声明顺序。
  • 读写草稿、写附件不是界面槽，归 api/：三个权限 composer.readDraft / writeDraft / attachments——附件是加 / 列 / 移三动作一个权限，移只能动自己加的。
  • 触发符注册制：单个符号，触发后输入是筛选；弹层样式是宿主的，列表内容是插件的。抢注安装时提醒，先装者为准。/ @ 不开放。
  • 记号（chip）由插件一次给两份：label 给人看、send 给 AI（文字 / 附件 / 不发送三种），payload 宿主只搬运不解析、只还给写入它的插件；key 由宿主分配。手打的 # 不算记号。外形宿主固定，【icon | 文字】。
  • 编辑历史消息回填底部输入框，前面是一个锚点记号；删锚点即退出编辑；切换编辑对象直接清空、不做保护；发送时先删掉被编辑那条及其之后的对话再重发（截断重跑）。
  • 分支上旧的 beforeSend 整块移交原型（模型 + 上下文 + 增强整体交给一个插件）已废弃，按新边界重做。

还没定的事

触发符号的字符集（emoji、全角算不算单个字符）未定——见 requirements.html 的「还没定的事」。
